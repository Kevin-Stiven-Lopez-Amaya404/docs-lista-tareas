## Por qué no aplica

No hay servidor propio, base de datos ni datos en la nube: la app es estática en Vercel y las tareas viven en el navegador de cada usuario. No hay nada que monitorizar, respaldar ni recuperar del lado del proyecto.

## Cuándo se usaría

Si en algún momento hay backend. Mientras tanto, la única comprobación operativa es la de después de cada entrega ([10-devops/ci-cd.md](../10-devops/ci-cd.md#después-de-cada-entrega)).
