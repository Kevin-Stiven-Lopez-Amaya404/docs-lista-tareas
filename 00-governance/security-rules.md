# Reglas de seguridad documental

> Estado: 🟢 Estable | Última actualización: 2026-11-23
> Autor: Kevin-Stiven-Lopez-Amaya404 | Equipo: lista-tareas
Este repositorio y su tablero son públicos. Nunca se publica:

- Tokens, claves, contraseñas o variables de entorno (de GitHub, Vercel, Figma u otros).
- Correos, teléfonos u otros datos personales.
- Capturas con datos reales de usuarios ni con sesiones abiertas.
- Direcciones de vistas previas de Vercel protegidas (solo la de producción).

Si se publica algo así por error: se revoca la credencial primero y después se limpia el historial.
