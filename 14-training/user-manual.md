# Manual de usuario

> Estado: 🟢 Estable | Última actualización: 2026-11-23
> Autor: Kevin-Stiven-Lopez-Amaya404 | Equipo: lista-tareas
Abre https://lista-tareas-sage.vercel.app/ en el navegador.

| Para… | Haz esto |
|-------|----------|
| Agregar una tarea | Escribe en "Escribe una nueva tarea…" y pulsa **Agregar** o Enter |
| Completarla | Marca la casilla (o Tab hasta ella y Espacio). Vuelve a marcarla para dejarla pendiente |
| Editarla | Pulsa el ícono de lápiz, cambia el texto y pulsa **Guardar** o Enter. **Cancelar** o Escape deja el texto como estaba |
| Eliminarla | Pulsa el ícono de papelera. Se borra al instante, sin confirmación |
| Ver solo algunas | Elige **Todas**, **Pendientes** o **Completadas** |
| Borrar las completadas | Pulsa **Borrar completadas (N)** |

Las tareas se guardan solas en este navegador. Si borras los datos del sitio o usas otro navegador o dispositivo, no estarán.
