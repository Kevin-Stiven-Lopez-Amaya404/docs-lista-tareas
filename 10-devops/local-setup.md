# Setup local

> Estado: 🟢 Estable | Última actualización: 2026-11-23
> Autor: Kevin-Stiven-Lopez-Amaya404 | Equipo: lista-tareas
**Requisitos:** Node 24 y Git.

```
git clone https://github.com/Kevin-Stiven-Lopez-Amaya404/lista-tareas.git
cd lista-tareas
npm install      # primera vez
npm run dev      # servidor local de Vite
npm test         # pruebas con Vitest
npm run build    # build de producción en dist/
npm run preview  # sirve dist/ en local
```

`.gitattributes` fija finales de línea LF ([ADR-007](../05-architecture/decisions/records/ADR-007-finales-de-linea-y-plantilla-pr.md)).
