# Decisiones de arquitectura (ADR)

> Estado: 🟢 Estable | Última actualización: 2026-11-23
> Autor: Kevin-Stiven-Lopez-Amaya404 | Equipo: lista-tareas
Cada decisión relevante, técnica o de producto, se registra como un ADR en [`records/`](./records/) con el siguiente número libre, a partir de [_template-adr.md](./_template-adr.md).

- **Estados:** PROPOSED · ACCEPTED · SUPERSEDED (indicar por cuál) · DEPRECATED.
- Un ADR aceptado no se reescribe: si cambia la decisión, se crea uno nuevo que lo reemplaza.
- Las decisiones anteriores a esta estructura están archivadas en [99-archive/old-decisions/decisiones.md](../../99-archive/old-decisions/decisiones.md) y convertidas en ADR-001 a ADR-009.

Índice: [records/README.md](./records/README.md).
